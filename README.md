## About Me 🧑‍💻

I build things end-to-end — from **Rust daemons** and **embedded firmware** on Arduino/ESP32, to **full-stack web apps** in JavaScript, TypeScript, and PHP/Laravel, down to the **self-hosted infrastructure** they run on (Proxmox, Docker, Linux servers).

I enjoy the whole stack: writing low-level code that talks to hardware over USB/I2C, designing APIs and dashboards that make sensor data useful, and automating deployments so everything just runs. Currently deep into Linux systems programming, IoT monitoring systems, and homelab automation.


- 🔧 Building: real-time PC monitors, water level monitoring systems, OLED display daemons
- 🤖 Exploring: local LLM inference, AI agent orchestration, workflow automation
- 🖥️ Daily driver: Arch-based Linux + KDE
- ⚡ Fun fact: my keyboard's OLED screen runs code I wrote

## Featured Projects 

###  ss-oled — Linux OLED daemon for SteelSeries Apex Pro keyboards
Rust fork of apex-tux with per-provider dwell times, event-driven MPRIS switching, and custom MPRIS layouts for the keyboard's built-in display.
🔗 [immortal1sm/ss-oled](https://github.com/immortal1sm/ss-oled)

###  Arduino PC Monitor
Real-time PC system monitor on an SH1106 OLED driven by an Arduino over USB serial — swappable faces showing CPU/GPU usage, temps, power draw, RAM/VRAM, plus an MPRIS now-playing face. Python host with a robust serial protocol and auto-recovery.
🔗 [immortal1sm/arduino-pc-monitor](https://github.com/immortal1sm/arduino-pc-monitor)

###  Water Level Monitoring System
IoT system for rice fields using the JSN-SR04T ultrasonic sensor — Arduino firmware + serial-to-web pipeline feeding a dashboard with live visualization and threshold-based alerts.
🔗 [immortal1sm/water-monitoring-system](https://github.com/immortal1sm/water-monitoring-system)

###  Game Server Bot / Discord Docker Serverbot
Self-hosted Discord bots for managing Docker-hosted game servers via slash commands — secure REST API endpoints, real-time system telemetry streamed to channels, scheduled backups, health checks, and crash-recovery.
🔗 [immortal1sm/Game-Server-Bot](https://github.com/immortal1sm/Game-Server-Bot) · [immortal1sm/Discord-Docker-Serverbot](https://github.com/immortal1sm/Discord-Docker-Serverbot)
